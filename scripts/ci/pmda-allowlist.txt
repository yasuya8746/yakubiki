# PMDA ドメインの記載を許可するファイルの一覧(scripts/ci/check-pmda-access.sh が読む)
#
# !!! このファイルへの追記は、必ず PR で reviewer のレビューを受けること !!!
# PMDA は自動巡回を全面的に禁止している(docs/adr/0001、docs/adr/0004)。
# ここに載せてよいのは「PMDA へアクセスしないことが確かなファイル」だけ。
#   - 可: アプリが外部ブラウザで開くための URL テンプレートの定義ファイル(T05 以降で作成予定)
#   - 不可: 変換ジョブ(batch/)、スクリプト(scripts/)、CI(.github/)、テストコード(src/test、src/androidTest)
# 追記する PR には、そのファイルが PMDA へ通信しない理由を書くこと。
#
# 書式: 1行に1ファイル。リポジトリのルートからの実パスを書く。# 以降はコメント。
# 次の行があると、検査は終了コード 2 で失敗する:
#   ワイルドカード(* ? [)を含む / ディレクトリを指す(/ で終わる行を含む) / 追跡されているファイルに一致しない /
#   上の「不可」の場所を指す
# ルートの docs/ 配下の文書(*.md)は常に除外されるので、ここに書く必要はない。
#
# 例(T05 で URL テンプレート定義を作ったら、実際のパスに置き換えて行頭の # を外す):
#   app/src/main/assets/url-templates.json
