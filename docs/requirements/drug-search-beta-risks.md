# 医療情報アプリとしてのリスクと対策(薬剤検索アプリ β版)

- 作成日: 2026-10-26(第1版)/ 改訂: 2026-10-26(第2版: リンク方式)
- ステータス: 承認済み(第2版、2026-10-28 人間が承認)
- 関連: `docs/requirements/drug-search-beta.md`, ADR-0001〜0004

> 本書は法的助言ではない。薬機法・著作権・ストアポリシーの最終判断は、人間(必要に応じて法務・薬事の専門家)が行う。

## 0. 第2版での見直しの要点
- 本文(用途・副作用・併用禁忌)をアプリが持たなくなったため、**「解析誤りで併用禁忌が欠落する」「古い本文で判断される」リスクは大きく下がった**。臨床判断に使う内容は PMDA の原文になる。
- PMDA への自動アクセスをしないため、**PMDA 規約違反のリスクは「意図しない自動アクセス」に限られる**。
- 一方で、**リンク切れ・誤った薬へのリンク**、インデックスに無い薬が見つからないこと、オフラインで原文が見られないことが新しい主なリスクになる。
- 医療機器プログラムに当たる可能性は、第1版よりさらに下がる(5章)。

## 2. 免責表示(第2版で文言を変更)
- 表示箇所は第1版と同じく3か所: 初回起動時(同意必須)、設定画面(全文)、品目情報画面の末尾(短文)。
- 文案の骨子(最終文言は人間・必要なら法務が確定):
  - 本アプリは医療従事者向けに、薬剤名から PMDA(医薬品医療機器総合機構)の添付文書ページへ案内するものであり、**添付文書の内容は保持・表示していない**。診断・治療の判断は、最新の添付文書(原文)と専門的判断に基づくこと。
  - リンク先が目的の製品(販売名・規格)であることを、必ず開いたページで確認すること。リンク先の変更等により、正しく表示されない場合がある。
  - 検索用の品目情報は、厚生労働省「薬価基準収載品目リスト」(○年○月○日版)を加工して作成したもので、最新の収載状況と異なる場合がある。収載前の新薬や薬価未収載品は検索できない。
  - β版であり、検索漏れ・リンク不良がありうる。不良を見つけたら報告ボタンから知らせてほしい。
  - 本アプリは PMDA・厚生労働省が提供・推奨するものではない。
  - 本アプリの利用により生じた損害について、運営者は責任を負わない(責任制限の書き方は法務確認)。
- 免責文があっても、R11・R12 の技術的対策(一致確認の文言、上書き表、抜き取り検証)を省略しない。

## 3. 情報の鮮度
- 第2版では「本文の鮮度」はアプリの責任範囲から外れ、PMDA の原文が担う。アプリが示すのは**インデックスの鮮度**だけ。
- 表示する日時:
  - **データ版(元データの公表日/適用日)**: 検索画面に常時表示。
  - **最終確認日時**(運営者が厚労省の更新を最後に確認した日時)と**最終同期日時**(端末が最後に同期した日時): 設定画面に表示。
- 警告: 端末が7日(仮)以上同期できていない場合に検索画面で警告。元データは月次程度でしか変わらないため、第1版の「72時間」は短すぎるとして変更した。しきい値は人間が決める(D7)。
- 運営者側の監視: 最終確認日時が長く(例: 3日)更新されていなければ、変換ジョブの停止として runbook で対応する。

## 4. オフラインでの動作
- 検索・品目情報表示はローカルの Room DB のみで動作。初回は同梱データを使うため通信不要。
- **PMDA の原文はオフラインでは開けない**。ボタン押下時に通信が必要である旨を表示し、ブラウザを開かない。
- 同期は新DBに取り込み → 検証 → 切替 の順で行い、途中失敗で旧データが壊れない。
- 原文を端末に保存してオフライン表示する機能は、著作権・PMDA 規約の両面で不可のため、将来も「ライセンスを得た別データ源」を使う場合に限って検討する(新ADR)。

## 5. 薬機法・医療機器プログラムに関する注意点
- 厚生労働省は「プログラムの医療機器該当性に関するガイドライン」等で該当性の考え方を示している。一般論として、**情報を検索・表示するだけのプログラムは医療機器に該当しない例**として扱われている一方、**患者個別のデータを入力して診断・治療方針の判断を支援するプログラムは該当しうる**。最新のガイドライン本文と事例集は人間が確認すること。
- 第2版では、アプリは「薬剤名の検索」と「公式文書(PMDA)へのリンク」だけを行い、医療情報の本文すら表示しない。判定・計算・要約・推奨を一切行わないため、**該当する可能性は第1版よりさらに低い**と考える(最終判断は人間。D8)。
- 本β版の方針(第1版から継続):
  - 複数薬剤を入力して「併用可/不可」を判定する機能、患者情報を使う機能は入れない(将来入れる場合は該当性の事前確認を必須とし、新ADRを作成)。
  - 情報を独自に加工・重み付けして「推奨」を出さない。
- 広告規制(薬機法 第66〜68条等)への配慮:
  - 特定製品の推奨・優劣表示・ランキングをしない(並び順は名称順など中立的なルール)。
  - 医療用医薬品の情報は医療従事者向けであることを明示する(R6)。
  - 運営主体が製薬企業や関連事業者の場合は「医療用医薬品の販売情報提供活動に関するガイドライン」等の追加確認が必要(仮定 A5)。
- 個人情報: ログイン・患者情報を扱わないため個人情報保護法上のリスクは小さい。テスター募集時の Google アカウント(メールアドレス)と、報告ボタン経由で届くメール(差出人アドレスを含む)は、アプリ外で運営者が管理する。

## 6. 著作権・規約に関する注意点(第2版で新設)
- PMDA(人間が確認済み): 自動巡回・ダウンロードは全面禁止。添付文書の著作権は製造販売業者にあり、無断の複製・転載・頒布は禁止。リンクは事前連絡不要で自由だが、リンク先が移動したら速やかに修正する義務がある。
  - → 本文・PDF・画像をアプリ、配信データ、リポジトリ、テスト資材のいずれにも保存しない。スクリーンショットをストア掲載画像やリリースノートに使う場合も、PMDA ページや添付文書を写り込ませない。
- 厚労省「薬価基準収載品目リスト」(未確認): 政府標準利用規約(第2.0版)または PDL1.0 であれば、出典の表示と加工した旨の表示で再配布できる見込み。T01 で原文を確認する。
- アプリ名・アイコン・説明に「PMDA」「厚生労働省」を、公式・提携と誤解される形で使わない。

## 7. 人間が確認すべき点(本書分)
1. 免責文言の確定(法務確認の要否)。
2. 未同期警告のしきい値(仮: 7日)。
3. 医療機器プログラム非該当とする判断の確認(第2版の機能一覧を前提に)。
4. 運営主体の属性(製薬企業か否か)。
5. 原文をオフラインで見られないこと(R7)の了承。
6. リンク修正の担当者と目標時間(R16)。
