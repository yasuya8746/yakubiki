## 変更履歴
### 第2版(2026-10-26): リンク方式へ変更
- **理由**: PMDA の規約で、自動で巡回してダウンロードするアプリケーションが全面禁止されており、添付文書の著作権は製造販売業者にあって無断の複製・転載・頒布が禁止されているため、PMDA の本文を取得してアプリに保存する方式は不可。ユーザーが「リンク方式」に決定した。
- **主な変更点**:
  | 項目 | 第1版 | 第2版 |
  |---|---|---|
  | 要望3の詳細表示 | 名前・用途・成分・副作用・併用禁忌をアプリ内に表示 | **品目情報(品名・成分名・規格・メーカー・区分・コード)をアプリ内に表示し、用途・副作用・併用禁忌などの本文は PMDA 添付文書ページへのリンクで原文を見てもらう** |
  | データ源 | PMDA 添付文書(本文) | 厚労省 薬価基準収載品目リスト(検索インデックス用。ADR-0001 第2版) |
  | 1日1回の処理 | サーバが PMDA から本文を取得・解析し、アプリが同期 | サーバが厚労省リストの更新を確認し(β開始時は手動、規約確認後は1日1回)、アプリは1日1回、新しいインデックスとリンク情報を確認して保存 |
  | オフライン | 検索・詳細とも全て動作 | 検索と品目情報は動作。**添付文書の原文はオフラインで見られない** |
  | 初回データ | 初回同期でダウンロード | APK に同梱(初回から通信なしで検索可) |
  | 新しい要件 | – | リンクの切り替え・修正(FR-8)、リンク切れの報告(FR-8) |
  | 削除した要件 | – | 本文の表示、「情報なし。原本を確認してください」表示、添付文書の改訂年月表示、併用禁忌表の表示 |

## 目的・背景
- 医療従事者が、医療用医薬品を薬剤名で素早く探し、**公式の添付文書(PMDA 掲載の原文)にすぐたどり着ける**ようにする。
- β版は「一部の関係者だけに公開」し、検索の使い勝手、リンクの正確さ、運用(インデックス更新・リンク修正)の妥当性を検証することが目的。一般公開はしない。
- 開発期間は約1か月(4週)。ログイン・個人情報は扱わない。

### ユーザーの要望(原文の要約)
1. 医療従事者向けの薬剤検索アプリ
2. 一部の関係者だけに公開
3. 薬剤名で検索し、詳細(名前、用途、成分、副作用、併用禁忌)を表示。薬剤情報は1日1回ネットから集めてアプリ内に保存
4. β版。ログイン・個人情報は扱わない
5. 開発期間は約1か月

### 要望3の扱い(第2版。人間の承認が必要)
- 「詳細を表示」→ **アプリ内では品目情報を表示し、用途・成分の詳細・副作用・併用禁忌は PMDA の添付文書ページ(原文)へのリンクで表示する**。
- 「1日1回ネットから集めてアプリ内に保存」→ **アプリは1日1回、運営者が配信する検索インデックスとリンク情報の更新を確認して端末に保存する。添付文書の本文は集めず、保存もしない**。インデックスの元データ(厚労省リスト)は月次程度でしか変わらないため、実際にデータが変わるのは月に数回程度。

## 対象ユーザー
- 主: 医師・薬剤師・看護師など、医療用医薬品の添付文書を業務で参照する医療従事者(β参加者として招待された人のみ)。
- 想定人数: 数十名〜100名以内(仮定。ADR-0003 の配布方法選定に影響)。
- 利用場面: 病棟・薬局・外来での調べもの。院内で電波が不安定な場所もある(検索をオフラインで動かす根拠。ただし原文の閲覧には通信が必要)。
- 対象外: 一般の患者・家族(一般公開しないため。表示文言も医療従事者向けとする)。

## 用語
| 用語 | 意味 |
|---|---|
| 品名(販売名) | 製品名(例: ○○錠5mg) |
| 一般名・成分名 | 有効成分の名称 |
| 添付文書 | 医療用医薬品の公式文書。PMDA サイトで公開。著作権は製造販売業者にある |
| 薬価基準収載品目リスト | 厚労省が公開する、薬価基準に収載された医薬品の一覧(Excel)。本アプリの検索インデックスの元データ |
| 薬価基準コード | 薬価基準収載医薬品コード(12桁)。品目の識別に使う |
| YJコード | 個別医薬品コード。PMDA の URL に使われることがある(ADR-0004。未確認) |
| 検索インデックス | 元データから作った、検索用の品目表(本文は含まない) |
| データ版 | 運営者が配信する、ある時点の検索インデックス+リンク情報の一式 |
| リンク上書き表 | 品目ごとにリンク方式や URL を上書き・無効化する表(ADR-0004) |

## 機能要件
1. **FR-1 薬剤検索**(第1版から変更なし。ただし 1.2 に制約を追記)
   1. 品名・成分名で部分一致検索できる。
   2. ひらがな/カタカナ、全角/半角、大文字/小文字の違いを正規化して検索できる(例: 「ろきそ」「ロキソ」で同じ結果)。
      - **制約(第2版)**: 元データに読み(カナ)が無いため、漢字を含む名称(例: 酸化マグネシウム、漢方製剤)は**ひらがなの読みでは見つからない**。β では漢字で入力してもらう。読みの追加は D10 で判断する。
   3. 結果一覧には 品名・成分名・規格・製造販売業者 を表示し、名称類似薬を取り違えにくくする。
   4. 0件時は「該当なし」、データ版(元データの公表日)を表示し、「PMDA の検索画面で探す」ボタン(FR-2.3 の副ボタンと同じ動作)を表示する。収載前の新薬や薬価未収載品はインデックスに無い旨も添える。
   5. 並び順は名称順など中立的なルールとし、特定製品を推奨する並びにしない。
2. **FR-2 品目情報表示と PMDA 添付文書へのリンク**(第1版の「薬剤詳細表示」を**置き換え**)
   1. 表示項目: 品名、成分名、規格、製造販売業者、区分(内用薬/注射薬/外用薬/歯科用薬剤)、先発/後発の区分(元データにあれば)、薬価基準コード。**用途・副作用・併用禁忌などの本文は表示しない**。薬価は表示しない。
   2. 主ボタン「PMDA で添付文書を見る」: ADR-0004 の方式(個別ページ、または成分一覧ページ)で PMDA のページを外部ブラウザ(または Custom Tabs)で開く。
   3. 副ボタン「PMDA の検索画面で探す」: 品名をクリップボードにコピーし、PMDA の検索画面を開く。コピーしたことを画面に表示する。
   4. ボタンの近くに「開いたページの販売名・規格がこの画面と一致するか確認してください」と表示する。
   5. リンク上書き表で「リンク無効」とされた品目は、主ボタンを出さず副ボタンのみ表示する。
   6. オフライン時にボタンを押すと、通信が必要であることを表示する(ブラウザを開かない)。
   7. アプリは PMDA のページを事前読み込み・取得・保存・解析しない(Custom Tabs の事前読み込みも使わない)。
3. **FR-3 データ同期**(第2版で変更)
   1. 初回起動時は APK に同梱したインデックスとリンク情報を使う(通信不要)。
   2. アプリは1日1回、運営者が配信する manifest を確認し、新しいデータ版があればダウンロードして端末に保存する(ADR-0002 第2版)。
   3. 同期は WorkManager の定期ジョブで、ネットワーク接続時のみ実行する。失敗時は指数バックオフで再試行する。
   4. 同期中・失敗時もアプリは直前のデータで使い続けられる(更新は検証後に一括切替)。
   5. 設定画面から手動で「今すぐ更新」を実行できる(削減候補)。
4. **FR-4 情報の鮮度表示**(第2版で変更)
   1. 検索画面に「データ版: 薬価基準収載品目リスト ○年○月○日版」を表示する(元データの公表日/適用日)。
   2. 設定画面に「運営者が最後に更新を確認した日時」(manifest の最終確認日時)と「端末が最後に同期した日時」を表示する。
   3. 端末が7日(仮)以上同期できていない場合、検索画面に「インデックスが古い可能性があります(新しい薬が見つからないことがあります)」と表示する。色だけでなく文言・アイコンで伝える。
   4. (削除)第1版の「添付文書の改訂年月」「データ取得日時」の詳細画面表示は、本文を持たないため削除。本文の鮮度は PMDA の原文で確認してもらう。
5. **FR-5 免責表示**(文言を変更。仕組みは第1版と同じ)
   1. 初回起動時に免責事項・利用条件を表示し、同意しないと先へ進めない。同意状態は端末内にのみ保存する。文言の骨子はリスク文書 2章。
   2. 品目情報画面の末尾に短い免責文と出典を常時表示する。
   3. 設定画面から免責事項全文をいつでも参照できる。
6. **FR-6 オフライン動作**(第2版で変更)
   1. 同梱データがあるため、初回起動から通信なしで検索と品目情報表示が動作する。
   2. PMDA の原文はオフラインでは開けない(FR-2.6)。**これは第1版からの要件の後退であり、人間の承認事項とする**。
7. **FR-7 設定・アプリ情報**
   1. アプリバージョン、データ版、最終確認日時・最終同期日時、データの出典と利用条件(「厚生労働省『薬価基準収載品目リスト』を加工して作成」等。規約の求める形式で)、PMDA へのリンクである旨、オープンソースライセンス表示。
   2. フィードバック送付先(メールアドレスまたはフォームURL)の表示。
8. **FR-8 リンクの保守**(第2版で新規)
   1. PMDA の URL 形式(テンプレート)と品目ごとのリンク上書き表は、アプリの更新なしに配信データで差し替えられる。
   2. 品目情報画面に「リンクが開けない/違う薬が表示された」報告ボタンを置く。押すとメールアプリが起動し、品名・薬価基準コード・アプリ版・データ版が入った下書きを作る。送信するかは利用者が決める(自動送信しない)。
   3. 運営者は報告・定期確認でリンク不良を知ったら、目標時間内(仮: 確認から1営業日)に修正して配信する(運用要件。runbook に記載)。

## 非機能要件
| 区分 | 要件 |
|---|---|
| 性能 | 約2万品目のインデックスで、ミドルレンジ端末でも検索結果が入力から300ms以内に表示される(正規化した名称への部分一致検索。ADR-0005。約1.2万品目のため達成は容易な見込み) |
| データ量 | 同梱・配信するインデックスは圧縮後数MB以内(目標2MB。T02 で実測)。差分なしの日次確認は通信量10KB程度以内 |
| 端末負荷 | 同期は「ネットワーク接続あり」の条件で実行。端末では Excel 解析・HTML 解析をしない |
| 取得元への配慮 | **PMDA には、サーバからもアプリからも自動でアクセスしない**(リンクの死活確認も自動で行わない)。厚労省へのアクセスはサーバの変換ジョブだけで、1日1回1ページ+更新時のみ数ファイル(規約確認前は手動起動のみ) |
| オフライン | FR-6 のとおり。ネットワーク不可でもクラッシュ・無限ローディングしない |
| セキュリティ | ログインなし・個人情報なし。通信は HTTPS のみ(cleartext 禁止)。署名鍵・APIキー・google-services.json はリポジトリに含めない(CI シークレットで注入) |
| プライバシー | 検索語・閲覧履歴を外部送信しない。β版では解析SDKを入れない。外部への通信は「manifest・データの取得」と「利用者がボタンを押したときのブラウザ起動」「利用者が送るメール」だけ |
| アクセシビリティ | システムのフォントサイズ拡大(200%まで)で表示が崩れない。TalkBack で主要操作ができる。色だけで警告を伝えない |
| 対応OS | minSdk 26(Android 8.0)以上を仮定。targetSdk は Play の最新要件に合わせる |
| 保守性 | 単一 app モジュール、レイヤ構成は既存雛形(ui / domain / data(local, remote, repository) / di)に従う。変換ジョブは `batch/` |
| データ品質 | 変換ジョブは品目数・必須列の有無を検証し、品目数が前回比で大きく減った場合(例: 5%超)や列構成が変わった場合はデータ版を公開しない |

## 受け入れ条件
- [ ] 品名・成分名の部分一致で検索でき、ひらがな/カタカナ・全角/半角の違いを吸収する(漢字名称のひらがな検索は対象外)(FR-1)
- [ ] 検索結果一覧に 品名・成分名・規格・製造販売業者 が表示される(FR-1.3)
- [ ] 0件時に「該当なし」、データ版、「PMDA の検索画面で探す」ボタンが表示される(FR-1.4)
- [ ] 品目情報画面に 品名・成分名・規格・製造販売業者・区分・薬価基準コード が表示され、本文(用途・副作用・併用禁忌)と薬価は表示されない(FR-2.1)
- [ ] 「PMDA で添付文書を見る」で、抜き取り検証の対象品目(T17)が **正しい製品の** PMDA ページ(または成分一覧)を開く。誤リンク0件、リンク切れは上書き表で修正済み(FR-2.2)
- [ ] 「PMDA の検索画面で探す」で品名がコピーされ、検索画面が開く(FR-2.3)
- [ ] 一致確認の注意文が表示される(FR-2.4)
- [ ] オフラインでボタンを押すと、通信が必要である旨が表示され、ブラウザは開かない(FR-2.6)
- [ ] アプリから PMDA への通信が、利用者のボタン操作によるブラウザ起動以外に発生しないことを通信ログで確認(FR-2.7)
- [ ] 機内モードで、初回起動直後から検索と品目情報表示が動作する(FR-6)
- [ ] 1日1回の定期同期が登録され、配信側でデータ版が更新されると24時間以内(端末がオンラインの場合)に端末へ反映される(FR-3)
- [ ] 同期失敗時も直前のデータで利用でき、データが中途半端な状態にならない(FR-3.4)
- [ ] URL テンプレートとリンク上書き表を配信データで変更すると、アプリの更新なしにリンクが変わる(FR-8.1)
- [ ] 報告ボタンでメールの下書き(品名・コード・版)が作られ、自動送信されない(FR-8.2)
- [ ] データ版が検索画面に、最終確認日時・最終同期日時が設定画面に表示され、7日(仮)以上未同期で警告が出る(FR-4)
- [ ] 初回起動時に免責事項への同意が求められ、同意前は検索画面に進めない(FR-5)
- [ ] 出典(厚労省リスト)と利用条件が設定画面に表示される(FR-7)
- [ ] 2万品目相当のデータで検索応答300ms以内(QA が計測した端末・条件をテスト計画に記録)
- [ ] 検索語・閲覧履歴が外部に送信されていないことを通信ログで確認
- [ ] 関係者のみがインストールできる配布経路で配布できる(ADR-0003)
- [ ] リポジトリに秘密情報(鍵・APIキー・google-services.json 等)が含まれていない
- [ ] リポジトリに PMDA へ自動アクセスするコード(スクリプト・テスト・ジョブ)が含まれていない

## スコープ外(β版)
- **添付文書本文(用途・副作用・併用禁忌など)のアプリ内表示・保存・キャッシュ**(第2版で追加。著作権と PMDA 規約のため)
- **PMDA からの自動取得・自動巡回、およびリンクの自動死活確認**(第2版で追加。PMDA 規約のため)
- アプリ内 WebView での PMDA ページ表示・解析(第2版で追加)
- 読み(カナ)による漢字名称の検索(D10 で追加を判断)
- ログイン・ユーザー登録・アカウント管理、個人情報の取得
- 複数薬剤を入力して相互作用を自動判定する「併用チェック」機能
- 患者情報(年齢・体重・腎機能等)を使う投与量計算・個別化アドバイス
- お気に入り・履歴のクラウド同期(端末内の閲覧履歴もβでは任意。入れる場合も端末内のみ)
- バーコード(GS1)読み取りによる検索
- 一般用医薬品(OTC)、薬価未収載の医療用医薬品のインデックス化、後発品の切替提案、薬価表示
- iOS版、タブレット最適化、多言語対応
- 一般公開(Play 製品版リリース)

## 仮定・未確定事項
### 仮定(承認時に確認してほしい)
- A1: β参加者は100名以内。全員が Google アカウントを持ち、Play ストアを使える Android 端末を持つ。
- A2(第2版で変更): 検索インデックスの元データは厚労省「薬価基準収載品目リスト」とし、その利用条件は政府標準利用規約(第2.0版)または PDL1.0 で、出典表示により加工・再配布できる(**未確認。T01 で人間が確認**)。
- A3(第2版で変更): インデックスは APK に同梱し、運営者が静的ホスティングで差し替えを配信する。更新確認は β 開始時は手動、厚労省サイトに自動取得の制限が無いと確認できたら1日1回のスケジュール実行にする(ADR-0002 第2版)。
- A4: 配信に使う基盤(例: GitHub Actions + Cloud Storage / Firebase Hosting)の利用・費用は許容される(無料〜少額の見込み。第1版より小さい)。
- A5: 運営主体は製薬企業ではない(製薬企業の場合、販売情報提供活動ガイドライン等の追加考慮が必要)。
- A6: 開発体制はエージェント協調で、実装の実働は1名相当×4週として見積もる。
- A7: パッケージ名(applicationId)は `com.example.myapp` から変更する。正式名は未定。
- A8(第2版で新規): PMDA の個別ページへ直接リンクできる安定 URL があるかは未確認。無ければ成分一覧ページまたは検索画面への遷移になる(ADR-0004)。
- A9(第2版で新規): リンク不良の修正を担当する運用者を置ける(PMDA 規約上の修正義務のため)。
